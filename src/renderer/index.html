Toujours appliqué

        
    
          
  • Seules les déclarations, expressions et fonctions conformes aux documents officiels rapportent des points ; margin / margin-left et les sélecteurs combinés (ex. « div h1 ») sont acceptés (A11).
    • 
          
  • Une erreur reprise de façon cohérente ailleurs n'est pas sanctionnée en cascade ; une erreur de structure n'annule pas les critères qui en dépendent (A3, B4).
    • 
          
  • Code commenté non évalué ; code supplémentaire non demandé non pénalisé (A8). Erreur de syntaxe bloquante : sanctionnée une fois, la logique reste notée (A9).
    • 
          
  • Épreuve théorique : tous les critères sont notés par l'enseignant ; la grille est proposée sur 40 points, répartie équitablement (« 0,25 pt par question » = parts égales).
