Réglages IA (hybrideCorrecteur)

      

        
La correction hybride combine les règles automatiques et le modèle Claude (claude-opus-5-5), qui vérifie chaque critère dans le code ou la copie de l'élève. Toutes les notes restent modifiables avant l'export.

        
        

        
La clé est chiffrée avec le coffre Windows et stockée uniquement sur cet ordinateur. Les travaux des élèves sont envoyés à l'API Claude au moment de la correction.
